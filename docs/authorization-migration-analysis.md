## 0.1.42：保留原库、修改内部流程

用户澄清要求为修改原编辑器内部的授权行为，保留原库及对象。已接管：

- `ksolite` 原账号代理的登录、退出、旧自动登录、精确 `forbidEditInForceLogin` 查询及 `LoginSNAuth` 开关。其他业务键执行原函数，不把全部 SDK 功能关闭。
- 在原七个管理器决定之外，新增 34 个海外授权状态入口：登录检查、广播/SN/VIP 回调、旧状态加载/设置、试用与到期提醒、访客态、状态/来源字符串以及有效期限查询。
- 旧回调参数不再提供授权，全部读取已验签的本站状态。有效状态使用原编辑器本地兼容标签，旧云端来源返回 Invalid；不产生第三方云端凭据。
- 主线程本站通知同步存活 Qt 对象的兼容状态；对象采用弱引用，纯查询不锁原互斥锁以避免 authList 重入死锁。仅在有效/无效变化时写兼容设置，不增加后台轮询。
- 原构造、析构和 SN 对象保留以兼容外部消费者；原始 authList 保留为容器构造，同步五个已知来源。未知来源查询不能授权，未知哈希键没有直接清空。
- 两个框架均固定原始摘要、入口序言/字节及填充区；缺少自有模块时拒绝指定授权查询，并初始化有效的 Qt 返回值，避免隐藏返回指针损坏。

新增真实 ARM64 测试覆盖 x8 隐藏返回、缺少模块拒绝、无关查询保持原值；状态测试覆盖旧回调不能覆盖本站决定、通知合并、销毁对象跳过和持锁时纯 getter。宿主模块构建及完整签名校验通过，安装后官网签名有效且 common/enterprise/domestic 三个原生管理器均接受、level=2。

运行边界：新增海外状态入口没有逐项全部运行覆盖；当前自动恢复的 PDF 路径下 nativeStateBridge 尚未记录海外对象绑定。此诊断不等于旧入口没有改写，亦不能当作新状态入口已全部运行通过。按用户要求不继续文档功能验收，发布说明保留此边界。其他未审计权限、混合 PDF 权限及公共框架非授权服务维持原行为。
