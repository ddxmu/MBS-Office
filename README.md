# Mbs Office 自研模块

当前版本：0.1.12。

本仓库仅发布自行编写的 AI 接口、本机账号、界面路由和模块更新代码，不包含办公程序、办公引擎、模板、许可文件或原版资源。它不是完整办公软件的开源发行版，也不授予第三方程序的修改或再分发许可。

- AI：OpenAI 兼容服务的地址、密钥、模型拉取；润色、校对、翻译、问答、总结。密钥保存到 macOS 钥匙串。
- 账号：邮箱与密码登录 Mbs Office 自有账号服务；注册入口为 https://ttys.ddxmu.com/mbs/register，客户端登录使用 https://ttys.ddxmu.com/api/mbs/login。可选“记住账号密码”，凭据保存在本机钥匙串；登录成功提示会在 3 秒后隐藏；已登录后再次点击账号入口只显示短暂状态提示，不会重新弹出登录窗，右上角显示邮箱首字母。 登录命中区域只覆盖“立即登录”文字控件，右上角头像、升级、超级派和工具按钮不会误弹登录窗口。
- 更新：检查指定仓库的自研模块版本、显示下载百分比、校验 SHA-256 与签名；校验通过后会正常退出应用；如有未保存文档按系统提示保存，安装器随后自动替换模块并重启。更新器优先选择与当前版本匹配的增量包，并保留旧版本回滚备份。
- 路由：升级入口显示本机更新窗口；旧账号、文库和外部升级页面入口会被拦截；超级派入口连接 https://superpi.ddxmu.com/ 。

自研功能不设会员门槛；Mbs 账号只控制自研功能会话，不替代第三方授权，不解锁第三方付费服务。

## 编译

需要 macOS 13+、Apple Silicon 与 Xcode Command Line Tools。运行 `./scripts/build.sh` 编译自研模块动态库和签名校验安装器。`src/MbsUiActions.mm`、`src/MbsNativeBranding.mm` 与 `src/MbsPluginPaths.mm` 是宿主集成层源码，需要由对应宿主加载，不包含办公引擎。

## AI 接口

API 地址填写完整兼容接口前缀，例如 `https://你的服务器/v1`。模型列表使用 `GET /models`，文本操作使用 `POST /chat/completions`。仅运行操作时发送输入框中的文字；拉取模型不会上传文档，也不依赖 Mbs 账号登录。

## 发布范围

本地完整应用与本地差异包不会自动上传到本仓库。公开发布内容仅包含本仓库自研源代码及自研模块；完整应用安装镜像保存在本地发布目录。
