# Mbs Office 自研模块

当前版本：0.1.35。完整安装镜像保存在本机桌面 REA；GitHub 发布自研源码及签名模块增量包。

- 首页与文档窗口按当前会话显示账号名；未登录点击打开登录框，已登录点击查看账号信息。删除旧账号悬停骨架框，统一首页和登录页的字体及机器人插画。
- 账号默认保存 30 天可撤销会话，不保存密码。启动时静默联网验证，401/403 清除失效会话；临时网络故障仅允许恢复匹配账号、会话和设备的未过期签名凭证。
- 管理员可为注册账号生成 Mbs 授权码，设置等级、有效天数和设备上限，查看记录及撤销。客户端通过“账号 → Mbs 账号与授权…”兑换，显示签名验证后的等级和到期时间。服务端接入说明见 [server/ACTIVATION.md](server/ACTIVATION.md)。
- 账号刷新与状态提示使用普通窗口层级，后台验证不激活应用；删除鼠标移动时反复抬高账号悬浮层的逻辑。
- 旧账号错误页通过现成的“稍后登录”按钮完成正常启动回调；首页左下角提供刷新图标修复按钮，帮助菜单和关于窗口也可进入。
- 更新器匹配当前版本的签名增量包，正常退出后安装并自动重新打开，保留旧版回滚备份。本版提供 0.1.34 → 0.1.35 增量；自有首页图标随模块嵌入，其他版本需本机完整安装包。
- 旧启动错误页和旧云服务兼容提示静默处理，恢复回调仍在后台执行；点击首页修复按钮可查看实际回调结果。
- 账号首次自动激活获得一年标准授权；新设备联网绑定账号已有有效授权，遵守后台设备上限。到期后可兑换新码或同步网站续期。首页“服务”打开官网，“文档”打开文件选择框。

本仓库只包含 Mbs 自行编写的账号、AI、界面路由与更新模块，不包含完整办公内核、原版资源或许可文件。Mbs 授权码只验证自有账号授权，不是内置编辑器的原厂许可证，也不提供第三方云端或付费服务权限。本版恢复启动错误页原有的正常完成回调，不以账号状态文字代替实际文档编辑验收。旧网页组件的旧钥匙串读取直接返回拒绝访问，不修改钥匙串权限；Mbs 会话与自有 AI 密钥存储保持原样。

## 0.1.35 原有 PDF 编辑与保存

有效 Mbs 授权接入原有 PDF 编辑内容、文字编辑、图片编辑和图章的权限判断，继续使用原有保存及另存为。原生视图的提示开关随授权状态同步，关闭已授权账号的试用提示，不清除文档未保存标记。其他权限保留原有判断；没有增加独立编辑窗口或后台 PDF 程序。0.1.32 本地测试中用户已确认保存成功。

## 0.1.31 首页标志

首页机器人由 24×26 放大至 30×34，字样由 13.5 pt 放大至 17.5 pt，采用圆角粗体并调整图文间距。此版仅改首页标志，沿用 0.1.29 的原有 PDF 流程。

## 0.1.29 修正范围

删除未发布 0.1.28 中新增的独立 PDF 编辑窗口、菜单和后台 PDF 程序；首页“文档”及原 PDF 编辑按钮恢复原有流程。此修正没有解除原 PDF 组件的会员保存限制，不作为 PDF 编辑免会员修复完成交付。

## 编译

需要 macOS 13+、Apple Silicon 与 Xcode Command Line Tools。运行 `./scripts/build.sh` 编译自研模块动态库和签名校验安装器，运行 `sh scripts/build-host-module.sh` 编译包含首页图标的宿主模块。`src/MbsUiActions.mm`、`src/MbsNativeBranding.mm` 与 `src/MbsPluginPaths.mm` 是宿主集成层源码，需要由对应宿主加载，不包含办公引擎。

## AI 接口

API 地址填写完整兼容接口前缀，例如 `https://你的服务器/v1`。模型列表使用 `GET /models`，文本操作使用 `POST /chat/completions`。仅运行操作时发送输入框中的文字；拉取模型不会上传文档，也不依赖 Mbs 账号登录。

0.1.24 将演示的重复 AI 标签合并为一个自有入口，提供生成演示、写作和历史会话，均使用同一配置。图片调用 `/images/generations`，需要服务及当前模型支持；聊天模型不自动具备图片能力。演示内容可保存为可编辑 PPTX。文字和演示历史仅保存在本机，最多 30 条。

验证：`sh scripts/test-ai-features.sh` 使用独立目录、模拟服务及内存钥匙串，不读取个人 API 密钥。完整本地安装包使用 `package-local-release.py --full-only`，自动配置演示界面后重新签名。界面文件有变化时，打包器会拒绝生成无法完整应用这些改动的模块增量包。

## 发布范围

本地完整应用与本地差异包不会自动上传到本仓库。公开发布内容仅包含本仓库自研源代码及自研模块；完整应用安装镜像保存在本地发布目录。
