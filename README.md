# Mbs Office 自研模块

当前版本：0.1.7（登录成功后返回主界面并显示账号状态）。

本仓库仅发布自行编写的 AI 接口、本机账号和模块更新代码，不包含 WPS/金山办公程序、办公引擎、图标、模板、许可文件或原版资源。它不是完整办公软件的开源发行版，也不授予第三方程序的修改或再分发许可。

- AI：OpenAI 兼容服务的地址、密钥、模型拉取；润色、校对、翻译、问答、总结。密钥保存到 macOS 钥匙串。
- 账号：邮箱与密码登录 Mbs Office 自有账号服务；注册入口为 https://ttys.ddxmu.com/mbs/register，客户端登录使用 https://ttys.ddxmu.com/api/mbs/login，只保存内存会话令牌，不保存密码。
- 更新：检查指定仓库的自研模块版本、显示下载百分比、校验 SHA-256 与签名；校验通过后保存文档并退出，安装器会自动替换模块并重启。

自研功能不设会员门槛；Mbs 账号只控制自研功能会话，不替代第三方授权，不解锁第三方付费服务。

## 编译

需要 macOS 13+、Apple Silicon 与 Xcode Command Line Tools。运行 `./scripts/build.sh` 编译自研模块动态库。此动态库需要由宿主程序调用头文件中的 C 接口，不包含文档编辑器。

## AI 接口

API 地址填写完整兼容接口前缀，例如 `https://你的服务器/v1`。模型列表使用 `GET /models`，文本操作使用 `POST /chat/completions`。仅运行操作时发送输入框中的文字；拉取模型不会上传文档。

## 发布范围

本地完整应用与本地差异包不会自动上传到本仓库。公开发布内容仅包含本仓库自研源代码及自研模块，发布前以实际验收记录为准。
