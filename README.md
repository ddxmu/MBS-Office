# Mbs Office 自研模块

当前开发版本：0.1.17（本机验证版，尚未公开发版）。

0.1.17 修复默认语言资源遗漏的应用名称，使系统识别为 Mbs Office。安装器暂存应用时也修正同一组名称，内部可执行文件和账号/授权校验保持原样。编辑器在线激活仍未实现。

0.1.16 增加网页登录回传：仅点击“网页登录”创建 5 分钟的一次性连接，网页登录后由发起请求的 App 领取独立会话。保持登录仍为 30 天；密码不保存在客户端。此账号连接不代表编辑器授权激活。

本仓库仅发布自行编写的 AI 接口、本机账号、界面路由和模块更新代码，不包含办公程序、办公引擎、模板、许可文件或原版资源。它不是完整办公软件的开源发行版，也不授予第三方程序的修改或再分发许可。

- AI：OpenAI 兼容服务的地址、密钥、模型拉取；润色、校对、翻译、问答、总结。密钥保存到 macOS 钥匙串。
- 账号：邮箱与密码登录 Mbs Office 自有账号服务；注册入口为 https://ttys.ddxmu.com/mbs/register，客户端登录使用 https://ttys.ddxmu.com/api/mbs/login。默认保持登录状态（现有服务会话期限 30 天）；本机只保存可撤销的会话令牌，不保存密码。重启时静默向 `/api/mbs/me` 验证，过期后要求重新登录。登录成功提示在 3 秒后隐藏；账号卡片读取真实会员字段并提供 `https://ttys.ddxmu.com/mbs/vip` 升级入口。网页登录只在点击对应按钮后打开；网站回传已部署，成功后会自动关闭发起请求的 App 登录窗口。
- 更新：检查指定仓库的自研模块版本、显示下载百分比、校验 SHA-256 与签名；校验通过后会正常退出应用；如有未保存文档按系统提示保存，安装器随后自动替换模块并重启。更新器优先选择与当前版本匹配的增量包，并保留旧版本回滚备份。
- 路由：升级入口只响应实际“升级”按钮；旧账号、文库和外部升级页面入口会被拦截；旧机器人头像和超级派入口已移除。
- 离线启动：原登录页不可用时，使用其现成的“稍后登录”按钮完成离线兼容回调；不再仅关闭 Cocoa 窗口而跳过后续状态恢复。本轮实际验证了文字编辑、加粗和保存，以及正常退出后重新打开。

自研功能不设会员门槛；Mbs 账号只控制自研功能会话，不替代第三方授权，不解锁第三方付费服务。

## 编译

需要 macOS 13+、Apple Silicon 与 Xcode Command Line Tools。运行 `./scripts/build.sh` 编译自研模块动态库和签名校验安装器。`src/MbsUiActions.mm`、`src/MbsNativeBranding.mm` 与 `src/MbsPluginPaths.mm` 是宿主集成层源码，需要由对应宿主加载，不包含办公引擎。

## AI 接口

API 地址填写完整兼容接口前缀，例如 `https://你的服务器/v1`。模型列表使用 `GET /models`，文本操作使用 `POST /chat/completions`。仅运行操作时发送输入框中的文字；拉取模型不会上传文档，也不依赖 Mbs 账号登录。

## 发布范围

本地完整应用与本地差异包不会自动上传到本仓库。公开发布内容仅包含本仓库自研源代码及自研模块；完整应用安装镜像保存在本地发布目录。
