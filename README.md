# Mbs Office 自研模块

当前版本：0.1.23。完整安装镜像保存在本机桌面 REA；GitHub 发布自研源码及签名模块增量包。

- 首页与文档窗口按当前会话显示账号名；未登录点击打开登录框，已登录点击查看账号信息。删除旧账号悬停骨架框，统一首页和登录页的字体及机器人插画。
- 账号默认保存 30 天可撤销会话，不保存密码。启动时静默联网验证，401/403 清除失效会话；临时网络故障仅允许恢复匹配账号、会话和设备的未过期签名凭证。
- 管理员可为注册账号生成 Mbs 授权码，设置等级、有效天数和设备上限，查看记录及撤销。客户端通过“账号 → Mbs 账号与授权…”兑换，显示签名验证后的等级和到期时间。服务端接入说明见 [server/ACTIVATION.md](server/ACTIVATION.md)。
- 账号刷新与状态提示使用普通窗口层级，后台验证不激活应用；删除鼠标移动时反复抬高账号悬浮层的逻辑。
- 旧账号错误窗口在显示入口关闭，替代定时点击旧“稍后登录”按钮的处理。
- 更新器匹配当前版本的签名增量包，正常退出后安装并自动重新打开，保留旧版回滚备份。本版提供 0.1.22 增量；自有首页图标随模块嵌入，其他版本需本机完整安装包。

本仓库只包含 Mbs 自行编写的账号、AI、界面路由与更新模块，不包含完整办公内核、原版资源或许可文件。沿用 0.1.18 已验证的本地自有授权适配；Mbs 授权码不是原厂签发许可证，也不提供第三方云端或付费服务权限。高级编辑功能的验收范围以发布记录为准。旧网页组件的旧钥匙串读取直接返回拒绝访问，不修改钥匙串权限；Mbs 会话与自有 AI 密钥存储保持原样。

## 编译

需要 macOS 13+、Apple Silicon 与 Xcode Command Line Tools。运行 `./scripts/build.sh` 编译自研模块动态库和签名校验安装器，运行 `sh scripts/build-host-module.sh` 编译包含首页图标的宿主模块。`src/MbsUiActions.mm`、`src/MbsNativeBranding.mm` 与 `src/MbsPluginPaths.mm` 是宿主集成层源码，需要由对应宿主加载，不包含办公引擎。

## AI 接口

API 地址填写完整兼容接口前缀，例如 `https://你的服务器/v1`。模型列表使用 `GET /models`，文本操作使用 `POST /chat/completions`。仅运行操作时发送输入框中的文字；拉取模型不会上传文档，也不依赖 Mbs 账号登录。

## 发布范围

本地完整应用与本地差异包不会自动上传到本仓库。公开发布内容仅包含本仓库自研源代码及自研模块；完整应用安装镜像保存在本地发布目录。
