# 编辑器在线激活：当前边界与未决项

核对日期：2026-10-20。

Mbs 网站账号服务与内置编辑组件的账号、许可系统是独立的。自有服务签发的 Mbs 凭证能够证明账号、会话、安装 ID 与有效期；它不构成编辑组件原厂签发的许可证。当前源码与本机文件中没有找到可验收的正式授权 SDK、企业激活码或授权服务接入配置。

旧提示短暂出现的直接原因是 `src/MbsUiActions.mm` 的 `MbsUseNativeOfflineAction`：监听器在原“账号登录”错误窗口已经显示后，才执行其“稍后登录”动作。现有组件的该动作会提交 `offlineUseComp`，属于离线兼容流程。因此不能将这一路径描述成纯在线启动，也不能通过隐藏窗口宣称在线激活完成。

本轮核对的安装版账号组件 SHA-256 为 `e2d22679b4dcf45771a98803d5716e647f461a3e30ef59f1facf8554b2bba6e9`，与已有启动流程分析目标一致。上述证据解释了旧提示与自有登录之间的关系，并不能证明全部工具栏置灰问题都由同一原因引起。

正式接入仍需要编辑器认可的授权来源及接口约定，并实测成功、拒绝、过期、断网和重启后的授权状态。如果没有这些接入条件，需要另行确定可独立授权的编辑器替换方案；更换内置引擎会影响文档兼容性与现有功能，不能当作小范围页面修复直接交付。

0.1.19 仅发布已完成的自研登录页面与账号恢复源码，不包含“编辑器正式在线激活已完成”的承诺。
