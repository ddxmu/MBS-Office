# Mbs Office V0.1.43 最近文档记录

- 在原首页“最近”位置显示已打开、恢复或保存的本机文档，提供文件名、位置、修改时间、大小及点击打开功能。
- 打开完成后登记；失败、尚在加载及未保存的新建文档不生成记录。首次成功保存及另存为后登记实际新路径。
- 同一路径重复打开或保存只保留一项；同名不同路径分别保留，保存后更新文件信息和顺序。
- 本机私有缓存保存最近100项，重启后恢复显示；不依赖旧云记录页面，不增加轮询进程、独立窗口或编辑程序。
- 修复候选版载入已有记录时的启动崩溃；首页直接读取本机记录，不再调用该候选版的私有Qt记录写入适配。
- 沿用0.1.42的授权和文档编辑、PDF保存实现；未改动原生框架文件。
