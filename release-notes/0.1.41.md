# Mbs Office V0.1.41 网站授权接入（本机候选）

- 七个已审计的原生授权管理器入口改为直接查询 Mbs 已验签的有效授权；缺少自有校验模块时拒绝授权，不回退原授权。
- 自有网站签名响应必须包含有效激活信息才可用于编辑；到期、撤销、设备超限或仅登录的状态不再开启编辑。
- 已核实的 PDF 文字及图章权限查询不再回退原会员权限。
- 账号面板显示网站授权状态、授权计划和实际授权到期日期；不再以旧原厂许可字段判断本站授权是否有效。
- 到期时更新授权状态；已验签的撤销结果在缓存写入失败时也立即停止当前进程授权。
- 保留 0.1.40 稳定程序及官网代码、数据库备份，回退工具默认不覆盖账号和业务数据。
- 仅为第一阶段隔离候选。海外授权状态机、其他功能权限查询和授权变化回调尚未完全替换；不能宣称已完全脱离原激活体系。
- 官网真实续期验签与授权生命周期测试通过。用户已确认文档功能可用并要求停止功能验收，本机安装按此范围进行，不标为全功能独立版。
- 未修改官网代码或授权记录。只提供完整本机候选包，不能通过现有自研模块增量包交付本次原生库变更。
