# Mbs Office V0.1.42 原编辑器授权流程适配

- 保留原编辑器、库文件与对象构造，在原函数入口修改账号和授权流程。
- 原 SDK 登录、退出转到 Mbs 网站账号；旧自动登录与 SN 登录联动停止参与本站授权。
- 旧强制登录禁编辑查询改为本站已验签授权；其他 SDK 业务查询保留。
- 已核实的海外登录检查、旧广播、SN／VIP 回调、授权加载、试用判断和期限查询改为自有状态处理。
- 本站状态改变时同步原编辑器兼容状态；旧回调参数不能覆盖本站有效、到期、撤销或退出状态。
- 沿用 0.1.41 的文档实现及 PDF 保存修正，保留 0.1.41 与 0.1.40 回退备份。本机已安装，官网有效授权及三个原生管理器接受状态已确认。
- 签名与生命周期、原生状态、真实 ARM64 跳板和账号代理测试通过。按用户要求不重复文档功能验收；新增海外状态入口的逐项运行覆盖仍有限，不标为所有旧路径已完全验证。

这次替换的是已核实入口的内部行为；原库仍为原编辑器兼容对象和非授权业务服务。不表示所有旧代码已删除，或第三方云服务已替换成本站服务。

本版涉及原生框架入口修改，需要完整安装。公开附件仅含 Mbs 自研代码、模块及其签名，不包含完整编辑内核，也不是应用内可自动安装的旧版模块增量包。完整安装镜像另行交付。
