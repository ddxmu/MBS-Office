# 0.1.18 本机验证版

- 新增 Mbs 自有在线签名授权；服务器持有独立 P-256 私钥，客户端固定公钥验签，绑定账号、会话、安装 ID、随机挑战和有效期。
- 原授权校验保留为回退分支。自有授权不等同于原厂许可，也不改变云端付费服务权益。
- 删除跨窗口保留的原生控件裸指针，修复账号刷新时访问已销毁控件的崩溃。
- 账号头像缩小并移至账号位置；删除大范围登录点击拦截。原生文档标题栏未提供账号 AX 几何时，使用当前内置布局的 68×22 点范围。
- 新登录页使用动态 Mbs 图标；手动登录且自有授权被内核接受后，显示 3 秒成功提示。账号卡显示实时授权状态。
- 正常登录页面保留；仅在明确的加载失败页使用其已有恢复按钮。

已验证：真实线上签名及绑定、缓存恢复、篡改拒绝、注销撤销；测试副本的内核状态回读；文字输入、表格插入、保存、关闭重开。

未完成：旧组件启动错误页和离线兼容提示仍会短暂出现；其他高级功能未逐项验证；旧版本跨内核自动增量安装未完成。本版不标记正式发布，不上传完整编辑器和资源。
