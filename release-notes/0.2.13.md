# Mbs Office 0.2.13

- 基于 0.2.12 完整安装版更新，保留原有账号和网站授权逻辑。
- PDF 转换界面自动带入当前打开文件的名称、页数和大小，支持设置页码和输出目录。
- 接入本地 Word、Excel 转换引擎，输出保留原文件名，已有同名文件不会被覆盖。复杂版式、字体和分页请在转换后核对；扫描件不包含 OCR。
- 修复“输出为图片”误开格式转换界面的问题，提供独立的 PNG／JPEG 导出窗口、页码范围和 72–600 DPI 选项。
- 图片在本机逐页生成，无需上传 PDF 或安装 Python。多页图片按原文件名和页码命名。

本次新增转换引擎。完整安装包可直接覆盖安装；离线增量包仅适用于未经修改的 0.2.12，解压后运行其中的升级脚本。旧版应用内的模块更新器不支持此新增引擎，请使用这两种安装方式之一。
