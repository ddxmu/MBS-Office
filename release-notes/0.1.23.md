# Mbs Office 0.1.23

- 首页及打开文档后的右上角同步显示当前账号名，登录、恢复会话、切换账号和退出时更新。
- 账号入口保持蓝色；点击已登录账号查看账号信息，未登录时打开登录框。
- 移除鼠标悬停时的旧账号骨架加载框，点击区域按实际按钮位置计算。
- 首页和登录页采用统一字体与配色，加入机器人插画。
- 自有首页图标嵌入模块，0.1.22 增量升级也包含新版图标。

本机完整 DMG 和签名增量包保存在桌面 REA；GitHub 发布自有源码、模块和安装器。
本次增量仅适用于 0.1.22，其他版本使用完整安装包。更新前保存文档并正常退出。

本版为账号界面和外观修复，不代表新增编辑器原厂授权或完成高级功能全量验收。
