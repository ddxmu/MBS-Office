# Mbs Office 0.1.24

- “关于 Mbs Office”显示安装包的实际版本和可打开的 GitHub 地址。
- 演示只保留一个 Mbs AI 标签，提供 PPT、文档/大纲生成、单页/多页、图片、写作、改写、扩写、缩写、润色、更多、历史与设置。
- 所有操作共用已有 API 地址、钥匙串密钥与模型配置；模型既可拉取选择，也可手动输入。保存配置不发送请求。
- 演示生成结果可预览并保存为可编辑的 16:9 PPTX；导入 TXT、Markdown、DOCX 或 RTF 正文后，点击运行才发送给所配置的服务。
- 图片调用同一配置的 `/images/generations`，预览后可保存 PNG。需要服务和当前模型支持图片生成；仅支持聊天的模型会显示错误提示。
- 文字和演示历史仅保存在本机，最多 30 条，恢复历史不发请求。

本版改动包含演示界面文件，需完整安装；仅替换模块无法移除旧演示 AI 标签。当前状态以本地验证及安装记录为准，不代表已发布到 GitHub。
