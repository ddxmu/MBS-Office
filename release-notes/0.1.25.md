# Mbs Office 0.1.25

- 内置自有 Word、Excel、PowerPoint 和 PDF 独立编辑 Helper，支持 DOC/DOCX/RTF、XLS/XLSX/CSV、PPT/PPTX 和 PDF。
- 从 Finder、文件关联、首页最近文档或编辑器内部打开支持格式时，统一路由到独立编辑器，避免落入旧内核的访客工具栏。
- 启动独立编辑器前验证 Mbs 账号会话、设备绑定、签名、有效期和授权码绑定；无效时进入 Mbs 登录/授权入口，不伪造编辑器许可证。
- 管理端 `/admin/mbs-licenses/create` 签发的授权码继续作为客户端在线激活来源；成功兑换后重新打开文档即可进入对应独立编辑器。
- 本版包含完整 Helper 应用，必须使用完整安装镜像；不生成模块增量包。

独立编辑器来自本机 `XYZ Office/MyAI Office/ThirdParty` 的自有构建，随完整本地镜像嵌入。公开源码仓库只保存 Mbs 路由、授权校验和打包代码，不上传个人会话、授权码或服务器私钥。
